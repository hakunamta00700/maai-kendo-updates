# MAAI · 검의 거리 업데이트

MAAI의 공식 설치 파일과 자동 업데이트 정보를 배포하는 저장소입니다. 게임 소스 코드와 개발 이력은 포함하지 않습니다.

정식 버전은 이 저장소의 **Releases**에서 다운로드할 수 있습니다. 아직 릴리즈가 없다면 업데이트 기능이 포함된 첫 정식 버전을 준비 중입니다.

- Windows: `MAAI-windows-x64.zip`을 풀고 `MAAI.exe`를 실행합니다.
- Android: `MAAI-android.apk`를 설치합니다. 업데이트를 지원하는 버전은 새 APK를 자동 다운로드하며, Android가 허용하면 메뉴에서 자동 설치합니다. 시스템 설정 또는 설치 승인이 필요할 수 있습니다.
- Web: 배포된 게임을 열면 새 버전을 확인합니다. 플레이 중에는 업데이트를 보류하고 메뉴에서 적용합니다.
- 무결성: 첨부된 SHA-256 체크섬으로 설치 파일을 확인할 수 있습니다.

예전 임시 서명 APK를 사용했다면 첫 업데이트 버전을 설치할 때 한 번 삭제·재설치가 필요할 수 있습니다. 이후 버전은 동일한 서명을 사용합니다. 앱을 삭제하면 기기 내 설정도 삭제될 수 있습니다.

이 저장소의 `update.json`은 Windows·Android 클라이언트가 사용하는 업데이트 정보입니다. 배포 파일에는 필요한 엔진·음원·폰트 라이선스를 동봉합니다.
